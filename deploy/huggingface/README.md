# Metro Pulse

Demand forecasting and operational anomaly detection for the Mexico City Metro,
built on the city's open ridership data — 1,180,920 station-days, 195 stations,
2010–2026.

- `/` — dashboard: the network map, the stations flagged today, and observed vs
  expected vs forecast for any station.
- `/docs` — the API.

Source and full write-up: https://github.com/OscarJuarez/metro-pulse
